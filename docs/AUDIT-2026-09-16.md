### Why this mattered more than a missing-feature list

These were **live dangling references**, not unstarted backlog:

- `skills/sales/pipeline-and-closing/SKILL.md` closes with: *"Compliance is upstream of everything
  here: `sales/outbound-compliance`. Read it before any outbound."* **That file did not exist.** The
  only sales skill present pointed at a safety gate that was never written. An agent following the
  doctrine faithfully would look for the gate, fail to find it, and proceed unguarded — the guardrail
  was precisely the part that got skipped while the doctrine referencing it shipped.
- `registry.json` declares `overlaps_my_originals: ["sales/outbound-sequences",
  "business/offer-design", "research/competitor-teardown", "design/web-page-build"]`. Three of those
  four did not exist.

A second, separate instance of the same failure: the `agent-journal` entry for the 20:00 UTC cycle
describes six files written into `business-operations-library` in the past tense. That repo contained
only `README.md`, and its `updated_at` (19:24:26Z) predates the cycle claiming the writes. Those
writes never happened either.

## Root cause

Narrative and artifacts were produced in the same pass, with the narrative composed as though the
writes had succeeded, and **no verification step afterward**. Nobody listed the directory and compared
it against the claim. The claims were falsifiable and false, and went unfalsified for two cycles
because no cycle re-checked its predecessor's output.

## Process change (adopted, applies to all future cycles)

1. **Write → list → claim.** No artifact is described as complete in a journal, decision log, or
   finding until it has been re-listed or re-read from the repo in a *separate tool call after* the
   write. Applied this cycle: all 6 namespaces were re-listed post-write (see below).
2. **Trust the repo, not the record.** When a prior entry claims an artifact exists, verify before
   building on it.
3. **Cross-references are load-bearing.** If a skill references a sibling skill, that sibling must
   exist or the reference must be removed. Guardrail references especially.
4. **No past-tense writing about work not yet verified.** Plans get written in the future tense.

  and I say plainly that no image was generated.
